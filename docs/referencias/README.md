# Referencias del curso

Los PDF del curso son material del docente y no se versionan en este repositorio. Cada integrante los copia a esta carpeta desde la plataforma del curso con estos nombres:

| Archivo | Contenido |
|---|---|
| `Enunciados.pdf` | Banco de proyectos. El nuestro es el Proyecto 2 (páginas 7 y 8) y las reglas comunes están en las páginas 2 y 3 |
| `Protocols.pdf` | Diapositivas del curso. Relevantes: 17 a 43 (contraseñas, KDF memory-hard) y 193 a 195 (TLS 1.3 record, AEAD y nonces) |

El resumen de lo que exige el enunciado está en `docs/requisitos_entregable2.md`.
